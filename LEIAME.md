# Design do Projeto Final

Guardem nesta pasta os três ficheiros exportados do Google Stitch:

- `DESIGN.md`: o design system (cores, fontes, tamanhos, espaços, cantos e componentes);
- `screen.png`: a imagem da página desenhada;
- `code.html`: o código gerado pelo Stitch (só para consultar: não se liga a nenhuma página do site).

Guardem também o pedido que escreveram no Stitch, num ficheiro `pedido.txt`.
